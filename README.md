# step by step

kyeonkim의 개인 블로그입니다. 한 걸음씩 만들며 배운 것들을 기록합니다.

## Stack

- [Jekyll](https://jekyllrb.com/) + GitHub Pages (GitHub Actions 배포)
- 직접 만든 커스텀 테마 (외부 프레임워크 없이 HTML/CSS/바닐라 JS)
  - 다크모드, 클라이언트 검색, 무한 스크롤, 목차, 태그 필터, 클랩·조회수
- 댓글: [giscus](https://giscus.app/) (GitHub Discussions)

일부 플레이스홀더 이미지는 [Mediumish](https://github.com/wowthemesnet/mediumish-theme-jekyll) 테마(MIT, `LICENSE.txt`)에서 가져왔습니다.
